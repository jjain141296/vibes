# Tic Tac Toe Game

A simple, interactive Tic Tac Toe game built with HTML, CSS, and JavaScript.

## Features
- Clean, modern UI
- Turn-based gameplay
- Win detection with highlighted winning sequence
- Draw detection
- Easy restart functionality
- Responsive design

## How to Play
1. Open `index.html` in your web browser
2. Players take turns clicking on cells to place their X or O
3. The game automatically detects wins or draws
4. Click the "Restart Game" button to start a new game

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES6+)
